# 天猫复购预测数据集：数据字典

> 数据来源：阿里云天池「天猫复购预测」比赛数据集。
> 官方入口：https://tianchi.aliyun.com/dataset/161265
> 本字典根据本地实际文件核对生成，更新时间：2026-10-15。

## 文件清单

| 文件 | 作用 | 本地大小（约） |
|---|---|---|
| `train_format1.csv` | 训练集：用户-商家样本及复购标签 | 3.5 MB |
| `test_format1.csv` | 测试集：需要预测复购概率的用户-商家样本 | 3.3 MB |
| `user_info_format1.csv` | 用户画像：年龄区间、性别 | 4.5 MB |
| `user_log_format1.csv` | 用户行为日志：用户对商品的点击/加购/购买/收藏 | 1.9 GB |

## 字段说明

### 1. train_format1.csv

| 字段 | 类型 | 说明 |
|---|---|---|
| `user_id` | 整数 | 购物者的唯一 ID 编码 |
| `merchant_id` | 整数 | 商家的唯一 ID 编码 |
| `label` | 枚举 | 1 表示该用户是该商家的复购买家；0 表示不是；-1 表示该用户不是该商家的新客户，不在预测范围内 |

### 2. test_format1.csv

| 字段 | 类型 | 说明 |
|---|---|---|
| `user_id` | 整数 | 购物者的唯一 ID 编码 |
| `merchant_id` | 整数 | 商家的唯一 ID 编码 |
| `prob` | 浮点数 | 提交答案用，原始测试集中为空，需要预测后填入复购概率 |

### 3. user_info_format1.csv

| 字段 | 类型 | 说明 |
|---|---|---|
| `user_id` | 整数 | 购物者的唯一 ID 编码 |
| `age_range` | 整数 | 年龄区间编码，部分为 0 或 NULL 表示未知 |
| `gender` | 整数 | 性别，0 表示女性，1 表示男性，2 和 NULL 表示未知 |

### 4. user_log_format1.csv

| 字段 | 类型 | 说明 |
|---|---|---|
| `user_id` | 整数 | 购物者的唯一 ID 编码 |
| `item_id` | 整数 | 商品的唯一 ID 编码 |
| `cat_id` | 整数 | 商品所属品类的唯一 ID 编码 |
| `seller_id` | 整数 | 商家的唯一 ID 编码，与 `merchant_id` 含义相同 |
| `brand_id` | 整数 | 商品品牌的唯一 ID 编码 |
| `time_stamp` | 字符串 | 购买时间，格式为 `mmdd`，例如 `0829` 表示 8 月 29 日 |
| `action_type` | 枚举 | 0 表示点击；1 表示加入购物车；2 表示购买；3 表示加入收藏夹 |

## 需要特别注意的地方

1. 行为日志里字段名是 `seller_id`，不是 `merchant_id`，但两者指的都是商家 ID，关联时要统一。
2. `time_stamp` 只有月和日，没有年份和小时，因此不能直接做完整的小时级时间序列分析，但可以做“日期趋势、双十一前后对比、工作日/周末”分析（年份由比赛背景补全）。
3. 训练集、测试集本身不包含年龄和性别，需要先用 `user_info_format1.csv` 通过 `user_id` 关联补充。
4. 测试集是预测目标，原始 `prob` 为空，不能当作真实复购结果使用。
5. 原始 ID 均为脱敏编码，无法反推真实用户或商品身份。
